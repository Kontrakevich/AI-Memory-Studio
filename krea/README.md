# Krea workflow — MEET_MY_YOUNGER_SELF_SCHOOL

Этот пакет фиксирует production preset для Krea + Seedance 2.0 под сценарий встречи взрослой версии человека со своей школьной версией.

## Входы
1. `child_photo` — точная идентичность ребенка.
2. `adult_photo` — точная идентичность взрослого.
3. `storyboard` — только движение, блокинг и композиция.
4. `era` — школьная эпоха.
5. Дополнительно: character sheets ребенка и взрослого.

## Reference hierarchy
- Фото определяют лица и возраст.
- Character sheets определяют одежду и аксессуары.
- Storyboard определяет только действие и расположение персонажей.
- Prompt определяет движение, эмоции и continuity.

## Рекомендуемый Krea flow
1. Подготовить character sheet ребенка.
2. Подготовить character sheet взрослого.
3. Сгенерировать meeting anchor в 9:16: ребенок стоит center-left, справа оставлено свободное пространство для входа взрослого.
4. Передать anchor + identity references + storyboard в Krea Video / Seedance 2.0.
5. Использовать `prompts/seedance_final.txt` как основной motion prompt.
6. Первый тест: 10 секунд, one continuous shot.

## Главное правило
Не просить модель сначала собрать двух персонажей уже во время сложного физического контакта. Самый надежный путь — сначала получить сильный anchor still с правильными лицами, одеждой, портфелями и пространственной географией, затем анимировать его.

## Основной сценарий
- 0–2s: ребенок стоит один.
- 2–3s: оборачивается вправо.
- 3–5s: взрослый физически входит справа.
- 5–7s: подходит, приобнимает, треплет волосы.
- 7–9s: оба поворачиваются к камере и улыбаются.
- 9–10s: слегка поднимают одинаковые портфели, мягко стукают ими и возвращают взгляд в камеру.

## Важное ограничение
Этот JSON — наш внутренний preset/spec. На момент сборки нет подключенного Krea API/plugin, через который ChatGPT может автоматически опубликовать Community App в аккаунте Krea. Поэтому spec предназначен для воспроизводимого ручного создания workflow в Krea и дальнейшей автоматизации, когда будет доступен официальный интерфейс/API.
