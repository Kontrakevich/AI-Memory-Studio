CHARACTER CARD GENERATION — CHILD / ADULT

Use the approved normalized portrait as the PRIMARY identity reference and the original source photograph(s) as secondary evidence.

Create one clean production character card for video generation.

CARD CONTENT:
1. FACE — front view
2. FACE — left or right profile
3. FACE — three-quarter view
4. FULL / THREE-QUARTER BODY SILHOUETTE

6. ACCESSORY breakdown

IDENTITY:
Preserve the exact same facial identity, age, hairstyle, proportions and visible distinguishing features from the approved normalized portrait.

ADULT CARD:

LAYOUT:
clean neutral production reference sheet,
plain light background,
consistent scale,
no decorative graphic design,
no invented text inside image unless generated as a separate deterministic overlay,

NEGATIVE:
no identity drift, no different face between angles, no age shift, no duplicate limbs, no wardrobe mutation, no missing accessories, no bag substitution, no stylization, no cartoon, no CGI look, no watermark.
